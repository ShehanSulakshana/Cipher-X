## 📌 Overview

> 💡 **Cipher-X** is a simple Python tool created to get hands-on experience with how cryptography actually works under the hood.

Instead of relying on high-level abstractions, this tool was built to write, test, and understand core encryption, decryption, and hashing algorithms from the ground up.

---

## ⚡ Key Highlights

-  **Symmetric & Asymmetric Encryption Concepts:** Easy-to-follow implementations of core ciphers.
-  **Key Management:** Clean patterns for key generation, storage, and handling.
-  **Hands-on Experimentation:** Great starting point for learning cybersecurity and applied cryptography.
-  **Lightweight & Fast:** Zero bloat, focused purely on core encryption utilities and clean execution.

## 🚀 Getting Started

Follow these steps to set up **Cipher-X** on your local machine.

### Prerequisites

Make sure you have the following installed:

*  **Git**
*  **Python 3.8+**

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/ShehanSulakshana/Cipher-X.git

# 2. Enter the project directory
cd Cipher-X

# 3. Install dependencies
pip install -r requirements.txt
```

---

## 💻 Quick Usage

Run the main application script to interact with Cipher-X:

```bash
python main.py
```
